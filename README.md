# REELS-MY

Проект для монтажа Instagram Reels: React, TypeScript и Remotion Studio.

## Запуск

Требуется Node.js 22 или новее (в облачной среде проверен Node.js 24).

```sh
npm ci
npm run dev
```

Studio покажет адрес и композицию `InstagramReel`. Проверка TypeScript:

```sh
npm run typecheck
```

## Ваше видео

1. Поместите видео в `public/media/input.mp4`. Медиафайлы в этой папке исключены из Git.
2. В `src/Root.tsx` измените `defaultProps.videoFile` на `media/input.mp4`.
3. Укажите начало исходного фрагмента в `trimStartSeconds` и громкость в `volume` (0–1).
4. Измените `durationInFrames` под нужную длительность: секунды × `fps`. По умолчанию 30 секунд, 30 fps, 1080×1920 (9:16).

Видео заполняет вертикальный кадр с обрезкой краёв (`objectFit: 'cover'`). При необходимости используйте `contain`, чтобы сохранить весь кадр. Пока файл не выбран, Studio показывает заглушку без запросов к отсутствующему видео. Субтитры, музыка, переходы и дополнительные фрагменты добавляются после получения исходника и задачи монтажа.

Рендер не выполнялся. Команды запуска только открывают редактор. Не добавляйте личные видео или секреты в Git.
